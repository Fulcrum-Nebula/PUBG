# PUBG Crosshair

Windows / Python 3。安装依赖：`py -3 -m pip install -r requirements.txt`；然后运行 `Crosshair.bat`。

- M：切换地图模式（隐藏准星）。Esc：退出地图模式。
- 地图模式下**按住 F2**：显示当前地图的点位参考图；松开隐藏。
- 按住 F2 时滚轮：切换地图图层；松开后滚轮不切换。右键按住仍临时隐藏准星。
- 当前只有艾伦格密室参考图，已保留原图上的彩色密室圈；只有一图时滚轮不会变更。
- 后续新地图：将图片放入 `maps/`，并把名称与相对路径登记到 `Crosshair.py` 的 `MAPS` 列表。

点位图目前按比例缩放、居中显示，**没有和 PUBG 地图坐标标定**；原图中社区水印和地图底图也会一并显示。若需在游戏原生地图上只叠密室圈，须先给游戏地图的屏幕边界／缩放与参考图对应关系。程序不读游戏内存。

运行逻辑测试：`py -3 -m unittest -v test_crosshair`。Windows 游戏内叠加显示仍须实机验证。
